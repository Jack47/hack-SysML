## LLM-maintained wiki

New sources and synthesized notes follow a three-layer workflow inspired by Karpathy's [LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f):

- [`raw/`](./raw/) stores immutable source material.
- [`wiki/`](./wiki/) stores agent-maintained, cross-linked synthesis.
- [`AGENTS.md`](./AGENTS.md) defines the ingest, query, and lint workflows.

Start browsing compiled knowledge from [`wiki/index.md`](./wiki/index.md). Existing topic directories remain available and can be migrated incrementally without breaking their current links.
